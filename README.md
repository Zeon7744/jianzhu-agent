# 建检智管 - 建筑行业检测及信息咨询公司 AI企业应用系统

## 系统概述
面向建筑行业检测及信息咨询公司的全功能AI企业应用系统，覆盖公司管理、运作、业务、人员、福利、后勤及财务等全方位模块。支持Windows、Linux、macOS三平台。

## 技术栈
- **前端**: React 18 + Ant Design 5 + ECharts 5 + Zustand + Vite
- **后端**: FastAPI + Uvicorn
- **数据库**: SQLite (零配置，跨平台)
- **AI层**: 规则引擎 + 结构化API（预留OpenAI/GPT集成接口）

## 环境要求
- Python 3.10+
- Node.js 18+
- Git

## 快速启动

### 方式一：一键启动（推荐）

#### Windows
```cmd
双击 start.bat
```
或命令行：
```cmd
start.bat
```

#### Linux / macOS
```bash
chmod +x start.sh
./start.sh
```

### 方式二：手动启动

#### 1. 初始化数据库
```bash
cd src/backend
python init_db.py
```

#### 2. 安装依赖
```bash
# Python 依赖
pip install -r requirements.txt

# Node.js 依赖
cd ../frontend
npm install
```

#### 3. 启动后端（终端1）
```bash
cd src/backend
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

#### 4. 启动前端（终端2）
```bash
cd src/frontend
npm run dev -- --host 0.0.0.0
```

- **macOS**: Bash 启动 `./start.sh`

所有路径使用 `pathlib.Path` 自动适配各操作系统。
