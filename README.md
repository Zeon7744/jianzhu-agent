# 建筑行业检测及信息咨询公司 - AI企业应用系统

## 系统架构

```
┌──────────────────────────────────────────────────────────────────┐
│                     AI企业应用系统 v1.0                          │
├──────────────────────────────────────────────────────────────────┤
│  前端层 (React + Ant Design + ECharts)                          │
│  ├─ 管理驾驶舱    ├─ 项目管理     ├─ 检测业务     ├─ 人力资源    │
│  ├─ 财务管理      ├─ 设备管理     ├─ 客户管理     ├─ 合规风控    │
│  ├─ 知识管理      └─ 数字员工中心 └─ 系统设置               │
├──────────────────────────────────────────────────────────────────┤
│  数字员工体系 (8位AI助手)                                       │
│  ├─ 智管(总经理助理)   ├─ 智财(财务主管)   ├─ 智项(项目经理)    │
│  ├─ 智检(检测主管)     ├─ 智人(HR主管)     ├─ 智客(客户总监)    │
│  ├─ 智法(合规顾问)     └─ 智设(设备管理员)                    │
├──────────────────────────────────────────────────────────────────┤
│  数据层 (SQLite + JSON文件)                                     │
│  ├─ 业务数据    ├─ 制度文档     ├─ 知识库       ├─ 运营日志     │
└──────────────────────────────────────────────────────────────────┘
```

## 功能模块

### 1. 管理驾驶舱
- 实时KPI监控（项目数、检测批次、应收账款、设备完好率）
- 经营趋势图表（收入vs支出）
- 数字员工在线状态监控
- 进行中项目列表
- 今日待办任务（按优先级排序）
- 预警信息时间线
- 风险雷达分析
- 检测业务分布饼图

### 2. 项目管理
- 项目全生命周期管理（立项→执行→报告→归档）
- 项目进度跟踪（百分比+阶段指示）
- 风险等级评估
- 合同额与回款管理
- AI智能排程建议

### 3. 检测业务
- 检测任务全流程管理
- 检测方法标准匹配
- 检测报告生成辅助
- 检测结果统计
- AI辅助质量分析

### 4. 人力资源
- 员工档案管理
- 资质证书追踪（到期预警）
- 部门人员分布
- 智能排班建议
- 培训发展管理

### 5. 财务管理
- 收支流水管理
- 发票管理
- 应收账款跟踪
- 成本分析报表
- 预算控制

### 6. 设备管理
- 设备台账管理
- 检定/校准计划
- 设备状态监控
- 维护记录追踪

### 7. 客户管理
- 客户档案
- 合同管理
- 服务记录
- 满意度跟踪

### 8. 合规风控
- 法规标准库
- 合规检查清单
- 风险预警
- 审计追踪

### 9. 知识管理
- 制度文档库
- 案例库
- 技术方案库
- 知识库检索

### 10. 数字员工中心
- 8位AI助手统一入口
- 对话式任务处理
- 智能报表生成
- 自动提醒推送

## 技术栈

- **前端**: React 18 + Vite 5 + Ant Design 5 + ECharts 5 + Zustand
- **后端**: Python FastAPI + SQLite
- **AI**: 数字员工体系（8位专业AI助手）

## 快速开始

### 前端
```bash
cd src/frontend
npm install
npm run dev
```

### 后端
```bash
cd src/backend
pip install -r requirements.txt
python app.py
```
