# 建检智管 - 建筑行业检测及信息咨询公司 AI企业应用系统

## 系统概述
面向建筑行业检测及信息咨询公司的全功能AI企业应用系统，覆盖公司管理、运作、业务、人员、福利、后勤及财务等全方位模块。

## 技术栈
- **前端**: React 18 + Ant Design 5 + ECharts 5 + Zustand + Vite
- **后端**: FastAPI + Uvicorn
- **数据库**: SQLite (可扩展至PostgreSQL)
- **AI层**: 规则引擎 + 结构化API（预留OpenAI/GPT集成接口）

## 功能模块

### 核心模块
| 模块 | 功能 | 数据量 |
|------|------|--------|
| 管理驾驶舱 | KPI总览、经营趋势、风险雷达、数字员工状态 | 实时 |
| 项目管理 | 全生命周期管理、进度追踪、风险预警 | 4+项目 |
| 检测业务 | 检测任务全流程、标准匹配、报告生成 | 20+任务 |
| 人力资源 | 人员档案、资质证书、智能排班 | 4+员工 |
| 财务管理 | 收支流水、成本核算、利润分析 | 20+记录 |
| 设备管理 | 设备台账、检定追踪、预测维护 | 3+设备 |
| 客户管理 | CRM档案、商机挖掘、服务跟进 | 12+客户 |
| 合规风控 | 法规跟踪、合规检查、风险预警 | 常更 |
| 知识管理 | 制度文档、标准规范、案例库 | 25+文档 |
| 数字员工 | 8位AI角色、智能问答、协同办公 | 实时 |

### 数字员工团队
1. **智管** - 总经理助理：经营监控、数据分析、决策建议
2. **智财** - 财务主管：账务处理、成本核算、税务合规
3. **智项** - 项目经理：进度管控、质量把关、协调沟通
4. **智检** - 检测主管：标准匹配、报告审核、质量控制
5. **智人** - HR主管：招聘配置、培训管理、绩效考核
6. **智客** - 客户总监：客户维护、商机挖掘、服务跟进
7. **智法** - 合规顾问：法规跟踪、风险提示、合规审查
8. **智设** - 设备管理员：台账管理、维护计划、检定追踪

## 快速启动

### 1. 初始化数据库
`ash
python src/backend/init_db.py
`

### 2. 启动后端 (终端1)
`ash
cd src/backend
python app.py
`
后端地址: http://localhost:8000

### 3. 启动前端 (终端2)
`ash
cd src/frontend
npm run dev
`
前端地址: http://localhost:3000
